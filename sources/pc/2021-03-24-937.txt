6. Requests
   A. Proposal to amend the Town of Mount Pleasant Code of Ordinances,
      Chapters 155 and 156, to change department titles and responsibilities.

      Mr. Pagliarini reviewed the amendments with the Commission.

  There being no comments, Mr. Wren closed the public hearing.

     Ms. Ireland moved for approval with the correction for 155.02(E)(1) to
  “…Director of…”. Ms. Smith seconded the motion. All in favor.

  B. Proposal to amend Zoning Code Section(s) 156.104 Density, and 156.302,
     Change of Town Boundaries, Chapter 156, Zoning Code of the Mount
     Pleasant Code of Ordinances. Amendments include updating the Future
     Land Use Map Designations to align with the newly adopted 2019
     Comprehensive Plan, and to update how a parcel is automatically classified
     upon annexation based on the new Future Land Use Map and any
     applicable overlays.

      Ms. Boyles reviewed the amendments with the Commission.

  There being no comments, Mr. Wren closed the public hearing.

      Ms. Smith moved for approval of the amendments. Mr. Campbell seconded
  the motion. All in favor.

  C. Proposal to amend Sections 156.318, Boulevard Overlay District, to amend
     the density allowed for residential uses in the overlay district.

      Ms. Boyles reviewed the amendments with the Commission.

      Ms. Ireland moved for approval clarifying the language to read “…except
  where the 2019-2029 Comprehensive Plan table 7-2 makes a specific
  recommendation.” Mr. Bennett seconded the motion. All in favor.

  D. Proposal to amend Code Section 152.27, Standards for Subdivision
     Proposals, of Chapter 152, Flood Damage Prevention, of the Mount
     Pleasant Code of Ordinances. Amendment includes standards for sketch
