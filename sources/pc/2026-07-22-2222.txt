E.    Vested Rights Extension Request, Patriots Annex Impact Assessment,
      Request for 1-year extension of Vested Rights for Patriots Annex Impact
      Assessment and Conceptual Plan Staff Report

     Mr. Stone reviewed staff comments with the Commission.

   Ms. Ireland asked if this can be denied. Mr. Stone answered that State Code
requires approval is there are no code changes.

    Mr. Pagliarini stated that this is the first impact assessment before the
Commission since the ordinance change giving the Commission approval
authority by Town Council. He stated that under State Law, five one-year
extensions are allowed and should be approved. He stated that if there is a
substantive change, it could mean that the extension would not be approved.

    Ms. Ireland asked how the vested right extension should not be approved
because the transportation analysis has not been updated and the data is
outdated. Mr. Pagliarini stated that the premise of the vested right extension is
to allow the development of the property as was previously approved. He stated
that only if the Town ordinances were changed that would not allow the
extension, then it could be denied.

        Mr. Bennett stated that only if there was a policy change, then the
    Commission could deny the extension. Mr. Pagliarini stated that a change in the
    development standards could mean an extension would not be approved.

        Mr. Barber asked about the traffic impact analysis and if it is an industry
    guideline. Mr. Pagliarini answered that the Town has an ordinance in effect that
    allows Town Council approval of impact assessments.

    Ms. Mansour asked if the requirements could change to allow traffic information
    to be updated. Mr. Pagliarini answered that the vested rights allow the continued
    approval of a previously approved plan.

       Mr. Barber asked if the traffic analysis data is determined and there are
    changes in the industry-wide standards, could that have an effect. Mr. Pagliarini
    answered in the negative.

        Mr. Bennett moved for approval. Mr. Smyth seconded the motion. All in favor.
