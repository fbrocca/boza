4.   Continued discussion pertaining to a text amendment to return density to the
     Comprehensive Plan Future Land Use Map (FLUM)

    Ms. Reed reviewed the item with the Committee and what the recommended
changes are for the density to be moved to the Comprehensive Plan. She stated that
this would go forward to the Planning Commission for a public hearing in August.
She stated that this would identify the density allowed for the various residential
zonings as was included prior to 2025. She stated that any properties recommended
for Community Facilities would require a planned development (PD) or FLUM
amendment.

    Mr. Tinkey asked if prior to 2025, any community facilities would require the PD
or FLUM. Ms. Reed answered in the affirmative. Mr. Tinkey asked the reason for
the change in 2014 to remove the density. Ms. Reed answered that she is not sure
the reason for the change but suspected that it was based on the interpretation from
the Zoning Administrator at the time. Mr. Tinkey asked if there were instances
where the long-standing uses were redeveloped that did not require a
Comprehensive Plan amendment. Ms. Reed answered that she is not sure and is not
aware of any of the community facility properties requesting residential uses during
that time. Mr. Tinkey asked if the approval would be provided by staff. Ms. Reed
answered for residentially zoned properties it would require a staff review, but Town
Council approval would be required if the property owner desired to increase density
or if a planned development is requested. Mr. Tinkey asked if there were any
previous requests that were contrary to the Comprehensive Plan recommendation.
Ms. Reed answered that between 2014 and 2025 there was a request to amend the
Comprehensive Plan, but the request was denied. Mr. Tinkey asked about financing
and if better loan terms would be allowed. Ms. Reed answered that she is not
familiar with lending standards and would not be able to address that question. Mr.
Tinkey suggested that there have been concerns that these changes might affect
having these types of supporting community facilities being included within the
neighborhoods and that this should be kept in mind moving forward.

     Ms. Hyatt asked if the proposed change would revert to the density included in
the Comprehensive Plan prior to the change in 2025. Ms. Reed answered in the
affirmative with a footnote stating that the FLUM and PD change would be required
for those properties recommended for community facilities. Ms. Hyatt asked if this
would apply only to churches and schools. Ms. Reed answered that this would apply
to all properties recommended for community facilities. Ms. Hyatt asked if this is a
